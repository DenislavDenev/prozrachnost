# Прозрачност

**По-ясна картина за България.** Независими инструменти върху публичните данни на държавата: всяко
число води до източника си и има дата.

| Инструмент | Папка | Какво показва |
|---|---|---|
| Прозрачност (хъбът) | [`hub/`](hub/README.md) | всички инструменти, работещи и в подготовка |
| Тендер | [`tools/tender/`](tools/tender/README.md) | обществените поръчки: възложители, фирми, лица и връзките между тях |
| Пътна обстановка | [`tools/patna-obstanovka/`](tools/patna-obstanovka/README.md) | трафик, ограничения, време по пътищата, катастрофи и оценка на риска |

Всеки инструмент се стартира и тества самостоятелно (виж README в папката му). CI пуска всички тестове
на всеки PR.

## Участие

Видя грешка: бутонът „Обратна връзка“ горе вдясно на всеки сайт. Искаш да помогнеш с код: прочети
[CONTRIBUTING.md](CONTRIBUTING.md) и [AGENTS.md](AGENTS.md) (правилата за issue, PR, тестове и лични данни).
