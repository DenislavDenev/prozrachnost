# Субсидии и помощи (`subsidii`)

Кой получава земеделски субсидии и помощи от Държавен фонд „Земеделие“, колко и от кой фонд: по финансови години, области, общини, мерки и получатели, с източник и дата за всяко число. Част от [Прозрачност](../../README.md). Порт 8005, план 03.

Данните са справката „Изплатени субсидии“ на ДФЗ, от архива на Наблюдател (CSV всеки понеделник; ДФЗ показва само две години, при нас остават всички). Инструментът не пита ДФЗ.

## Състояние

Първа част: данните (бронз, сребро, злато, проверки, сверка, свежест). Страниците, картата, CSV и JSON идват с втората заявка за промяна.

## Данни и правила

* бронз (архивът) → сребро (`silver`, формата на справката, интервали по дни) → злато (`gold`, общини, мерки, наблюдения, регистър), проверки в `db/checks/`; виж [docs/methodology.md](docs/methodology.md);
* източникът, форматът и какво не знаем: [docs/sources.md](docs/sources.md); личните данни: [docs/legal.md](docs/legal.md);
* лиценз на справката: не е посочен; показва се с източника, не се раздава.

## Стъпки (`python -m ingest.run --step X`)

`migrate`, `dfz` (новите файлове от архива, после златото), `gold` (`--rebuild`), `rebuild --fy`, `population` (жители от Население), `sample` (случайни фирми за ръчна проверка), `freshness`, `report`. Тежките стъпки вървят под общото заключване `/run/lock/prozrachnost-heavy.lock` през `subsidii-step` (виж частното репо).

## Тестове

```
SUBSIDII_TEST_DSN="dbname=subsidii_test" python -m pytest -q      # само в тестова база, името ѝ съдържа test
SUBSIDII_TEST_DSN="dbname=subsidii_test" python tests/mutations.py
```

Фикстурите (`tests/fixtures/dfz/`) са цели блокове от истинските файлове на архива (`tools/cut_fixtures.py`); имената на хора са заменени с „физическо лице №N“.
