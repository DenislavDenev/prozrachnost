# Училища

Инструментът е в начална разработка. Засега има проверен парсер за публикуваните резултати от НВО VII клас по училища. Данните не се публикуват на страница, преди да са готови импортът, сверката с регистъра и проверката за свежест.

## Проверка

От папката `tools/uchilishta/`:

```bash
python -m pytest -q
```

Източникът и ограниченията на тази стъпка са описани в [docs/sources.md](docs/sources.md).
