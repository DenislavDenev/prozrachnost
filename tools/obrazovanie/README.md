# Образование

Инструментът чете всички публикувани учебни години за НВО IV, VII и X клас, 16 ресурса за матури от 2015/2016 до 2025/2026 г. и кодовите списъци за защитени и средищни училища. Годините от 2021/2022 нататък се сверяват по код по НЕИСПУО с регистъра за същата година. По-старите резултати са означени като несверени. Таблото показва националния контекст с буквални бройки и дялове по клас. Картата е втора в менюто и показва наличните НВО и матури по общини, области, райони, макрорайони и държава; територия се свързва само по точната област и община от изпитния файл. Ако МОН е скрило броя явили се за матурите, средна оценка за засегнатата територия не се изчислява. Училищните списъци за НВО и матурите имат свързани филтри за област и община, търсене и CSV. Има профил на училище с история и статут по години, източници и методика. Адресът `/context` насочва към контекста на таблото. Наличните официални справки за профили и финансиране са свързани от страницата с източници; техните ключове и обхват не позволяват надеждно приписване към всеки училищен профил.

## Данните

От 11.11.2026 данните са в общата база `prozrachnost` ([tools/danni/README.md](../danni/README.md)):

| Схема | Какво |
|---|---|
| `obrazovanie_src` | приемната зона: редовете на всеки прочетен ресурс на МОН, както са в източника, с `load_id` |
| `obrazovanie` | чистите таблици: години на НВО VII, училища и резултати, ресурси и резултати на ДЗИ и на НВО IV и X, официалните списъци, националните бройки; описани с `COMMENT ON` |
| `pub_obrazovanie` | слоят за показване: това и само това четат страниците |

- Всеки прочетен ресурс е едно зареждане през общия модул `ingest/pipeline.py` (непроменено копие на `tools/danni/pipeline.py`). Пусканията, суровите файлове, задържането, дневникът на промените, правилата и свежестта са в общата схема `ops`.
- Отговор, в който липсва училище, ред или предмет от действащата версия, не я заменя, докато второ четене поне ден по-късно не каже същото. За националните бройки същото важи при спад на учениците, групите или училищата от един вид.
- Училищата и резултатите сочат към `core.municipality` и `core.settlement` (ЕКАТТЕ). Общината се намира по имената на областта и общината в източника; населеното място само ако името му е едно в общината (или в областта, когато файлът няма община). Иначе ключът е празен и редът се брои в правило с праг (`municipality_unmatched`, `ekatte_unmatched`, `nvo_municipality_unmatched` в `db/checks.toml`).
- Картата взима общините, областите и районите от `pub.municipality`, `pub.oblast` и `pub.nuts`. Копието на `municipality.csv` го няма.
- Слоят за показване се сменя само с публикуване в края на стъпка, след като всички правила минат (`db/publish/*.sql`). Всеки отговор носи номера на публикуването (`X-Publication`, `ETag`, `Last-Modified`), а една заявка чете една моментна снимка.
- Имена на хора източниците нямат: регистърът, изпитните файлове и списъците дават името на училището, не на директор или служител.
- Схемата на старата собствена база е в `db/legacy/` за справка.

## Проверка

От папката `tools/obrazovanie/` след `pip install -r requirements.txt`, в база с основата на `tools/danni`:

```bash
python -m ingest.run --step migrate
python -m ingest.run --step mon
python -m ingest.run --step history
python -m ingest.run --step legacy
python -m ingest.run --step dzi
python -m ingest.run --step nvo
python -m ingest.run --step status
python -m ingest.run --step context
python -m ingest.run --step check
python -m ingest.run --step freshness
uvicorn app.main:app --host 127.0.0.1 --port 8016
```

`build` строи чистите таблици наново от приемната зона (след смяна на местата в `core`). `replay` и `parity` бяха за преминаването: първата зарежда публикуваното в старата база от суровите ѝ файлове през същите парсери, втората сравнява старата база с общата ред по ред, по брой и по сборове.

За тестовете се използва само база с `test` в името и променливата `OBRAZOVANIE_TEST_DSN`. Тестовете искат и папката `tools/danni` до инструмента:

```bash
python -m pytest -q
python tests/mutations.py
```

Суровите отговори се пазят под `OBRAZOVANIE_DATA/raw/` (по подразбиране `/srv/prozrachnost/obrazovanie/raw/`) с име по sha256. Уеб процесът използва `OBRAZOVANIE_DSN` с роля, която чете само слоя за показване. Източниците и ограниченията са описани в [docs/sources.md](docs/sources.md) и [docs/methodology.md](docs/methodology.md).
