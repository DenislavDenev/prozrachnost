# Икономика

Икономиката на България в числа: инфлацията по всички групи стоки и услуги, БВП общо, по тримесечия и
по области, заплати, безработица, дълг и дефицит, цени на жилищата, сравнение с ЕС и валутните курсове
на БНБ от 1991 г. Всяко число води до източника си и има дата; флаговете на източника (предварителни,
оценка, прекъсване на реда) стоят до числото.

## Страници

| Адрес | Какво |
|---|---|
| `/` | изречение с ключовите числа и шест графики (инфлация, ръст, безработица, дълг, заплати, жилища) |
| `/inflaciya` | ХИПЦ по групи: какво движи инфлацията (приносът на всяка група: теглото ѝ по промяната), графика с бутони за основните групи, цени на производител, цена на тока за домакинствата, таблица; всички подгрупи, с търсене по име или код |
| `/karta` | интерактивна карта (приближаване, местене, избор) и списък за България (`?o=bg`: области, райони, макрорайони) или Европа (`?o=eu`: и държави), с полет между двете: БВП, БВП на човек (в € и по покупателна способност), население, а до районите и заетост, безработица (и на младите) и компенсация на един нает; данните от `/api/karta.json`; `/oblasti` води тук |
| `/rastezh` | Растеж: откъде идва ръстът на БВП (приносът на потреблението, инвестициите, износа и вноса), добавена стойност по отрасли, промишленост, търговия на дребно, строителство, бизнес и потребителско доверие, нощувки |
| `/zaetost` | Заетост и доходи: безработица по възраст и пол, заети по отрасли, заетост и безработица по райони, бедност |
| `/finansi` | Държавни финанси: салдо по подсектори, дълг по инструменти, разходи за лихви, дългосрочна лихва, прогнозите на МФ срещу случилото се (`/api/prognoza/<показател>.json`) |
| `/vanshen` | Външен сектор: износ и внос на стоки (месечно, по партньори, по вид и стокови групи), текуща сметка, преки инвестиции |
| `/pari` | Пари: лихви по кредити и депозити (България от 2026, еврозоната от 2003), кредити и депозити, междубанкови лихви, валутните курсове на БНБ; `/kursove` води тук |
| `/es` | България срещу ЕС по 14 показателя: класиране за последния период и линия във времето |
| `/sources` | всеки показател: набор, редове, период, кога е обновен и прочетен, състояние |
| `/how` | как работи: източници, проверки, флагове, превръщания |
| `/api/<показател>.json` | всеки показател като JSON, с филтри `?geo=BG,EU27_2020&coicop18=TOTAL&since=2020-01` |
| `/api/fx/<код>.json` | курсът на валутата за 1 евро |
| `/csv/<показател>.csv` | всички редове на показателя |
| `/healthz` | базата отговаря |

Показателите са в [`db/ref/indicators.csv`](db/ref/indicators.csv): нов показател е нов ред там (набор на
Eurostat, филтри, държави, праг за остаряване), без нов код. Българските имена са в
[`db/ref/labels.csv`](db/ref/labels.csv); имената на групите на ХИПЦ са от официалния български текст на
класификацията (ЕКОИКОП, версия 2, в Делегиран регламент (ЕС) 2024/3159) и се обновяват с
`python tools/build_coicop_labels.py` (виж скрипта).

## Данни

- **Контурите на картата**: всички от Eurostat GISCO в една проекция (EPSG:3035), за да може картата да
  лети от България до Европа: държавите 2024 и NUTS 2024 при 1:20 млн., България при 1:1 млн.
  (`tools/build_europe_map.py` пише `app/static/europe.json`). **Те не са под лиценза на репото**: GISCO ги
  дава само за некомерсиална употреба и с надпис „© EuroGeographics за административните граници“, който
  стои под картата.

- **Eurostat**, Statistics API (JSON-stat 2.0, CC BY 4.0): 43 показателя, около 730 хил. реда. ХИПЦ е по
  всички 495 групи от 1996 г., с теглата им; БВП по компоненти и отрасли; промишленост, търговия,
  строителство, доверие, туризъм; заетост и безработица (и по райони в цяла Европа); бедност; дълг по
  подсектори; лихви; външна търговия; платежен баланс и преки инвестиции.
- **ЕЦБ**, Data Portal API: лихвите на банките по нови кредити и депозити (за България от 2026, за
  еврозоната от 2003) и салдата на кредитите и депозитите (от 2022).
- **Министерство на финансите** (data.egov.bg): 13-те макроикономически прогнози от 2020 г. насам, за да се
  сравни прогнозата със случилото се.
- **БНБ**, валутни курсове: до 31.12.2025 в лева (от 1991), от 1.1.2026 референтните на ЕЦБ към еврото.

Подробно: [docs/sources.md](docs/sources.md). Изчисленията, сверките и проверката на тестовете:
[docs/methodology.md](docs/methodology.md).

## Как се пуска

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
export IKONOMIKA_DSN="dbname=ikonomika" IKONOMIKA_DATA=./.data
python -m ingest.run --step migrate
python -m ingest.run --step eurostat          # всички показатели (около минута)
python -m ingest.run --step bnb               # курсовете от последните 31 дни
python -m ingest.run --step bnb --backfill    # курсовете от 1991 (около 1400 заявки, часове)
python -m ingest.run --step freshness         # какво е закъсняло или задържано
uvicorn app.main:app --port 8025
```

Всяка стъпка печата един JSON ред; изходът е 1 при грешка или при непразно `problems`.

## Тестове

```bash
IKONOMIKA_TEST_DSN="dbname=ikonomika_test" python -m pytest -q     # базата се изтрива
IKONOMIKA_TEST_DSN="dbname=ikonomika_test" python tests/mutations.py
```

Без `IKONOMIKA_TEST_DSN` тестовете с база се пропускат; в CI вървят всички, срещу Postgres 17.
`tests/mutations.py` чупи нарочно всяко пазещо правило и проверява, че тестовете го хващат.
