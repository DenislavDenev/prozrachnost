## Не са в архива и защо

| Източник | Защо |
|---|---|
| ЦИК, сайтът на МФ, ИСУН | зад Cloudflare или F5: нужен е истински браузър; идват с инструментите си (08, 01, 02) |
| Съдебни актове (legalacts) | CAPTCHA, която не заобикаляме |
| ENTSO-E | нужен е ключ (безплатна регистрация на собственика) |
| Декларациите (`register.cacbg.bg`) | счупена TLS верига: клиентът трябва да добави междинния сертификат (идва с 10 Декларации) |
| ГРАО | 403 на скрипт; идва с 15 Население |
| Публични продажби на ЧСИ | обявите изчезват след продажбата, но са страници с търсене: идват с 22 Имоти |
| ЕСО производство, IBEX, ДФЗ de minimis и ПРСР, останалите страници на APEX | идват с инструментите си (19, 03) |
| ЦАИС ЕОП, Търговски регистър (SIGMA) | Тендер пази суровото си сам |
| Eurostat, курсовете на БНБ | Икономика пази суровото си сам; не се трият |
| БГТОЛ, ЛИМА (пътна обстановка) | текущо състояние на всеки 15 минути; Пътна обстановка пази само последното. История би значила снимка на всеки 15 минути: отделно решение |
| Регистър на минималните помощи, НАП длъжници | само справка по ЕИК, не се свалят масово по замисъл |
