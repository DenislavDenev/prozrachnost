# Държавна собственост

Самостоятелно приложение за каталога на публичните предприятия на АППК и партидите в Националния концесионен регистър. Профили, бордови наблюдения, отчетни метаданни, източникови документи, филтри, CSV и карта само на доказаните територии.

Страници: `/`, `/predpriyatiya`, `/predpriyatiya/id/<appk_id>`, `/predpriyatiya/<проверен ЕИК>`, `/koncesii`, `/koncesii/<UUID>`, `/karta`, `/sources`, `/how`, `/healthz`.

```sh
pip install -r requirements.txt
export SOBSTVENOST_DSN=dbname=sobstvenost
export SOBSTVENOST_DATA=/path/to/private/archive
python -m ingest.run --step migrate
python -m ingest.run --step appk
python -m ingest.run --step ncr
python -m ingest.run --step appk-details
python -m ingest.run --step ncr-details
python -m ingest.run --step pdfs
uvicorn app.main:app
```

`refresh` прави пълно ново четене на каталозите, профилите и отчетните метаданни. `--resume` преизползва проверени оригинали само за прекъснато наваксване; не е доказателство за нов планиран прочит. `--limit` маркира хода като непълен и връща неуспех. Файловият архив е отделна стъпка: последната действителна годишна отчетна година на всяко предприятие и файловете на НКР профилите. PDF, ZIP и OLE оригиналите се означават по действителния формат. `municipal` отказва публикация, докато индивидуалните набори и права не са валидирани.

За тестове се използва само `SOBSTVENOST_TEST_DSN=dbname=sobstvenost_test`: `pytest -q`, после `python tests/mutations.py`. Тестове с изтриване никога не се изпълняват в реалния или предварителния архив.

Прочетеният каталог на 01.10.2026 съдържа 288 предприятия и 1441 концесионни партиди; това не означава завършено покритие на всички профили, отчети и PDF. Актуалното покритие е в `/sources`. Няма финансови класации или общински редове без доказан източник. Виж [източници](docs/sources.md), [методология](docs/methodology.md) и [права](docs/legal.md).

--budget-seconds ограничава хода; --continue-pending продължава същия проверен обхват с реално четене на оставащите записи. Контролната точка е частна, атомична и проверена с хеш. --pending-only за pdfs пропуска хода, ако няма непълен архив. Нормален завършен следващ refresh започва нов пълен прочит. Непълният ход остава видим; не записва пълен успех.
