# Парламент

Как гласува Народното събрание: всяко гласуване от декември 2021 г. (47-о Народно събрание) насам, по
депутати и по парламентарни групи, в залата с анимация; колко често всеки депутат гласува, колко пъти
гласува различно от групата си, колко единни са групите и кои гласуват заедно. Всяко заседание е
сверено: поименното гласуване, преброено по групи, е гласуването по групи.

## Страници

| Адрес | Какво |
|---|---|
| `/` | изречение с ключовите числа, залата по групи, последното гласуване, последните и най-оспорваните гласувания |
| `/glasuvaniya?ns=52&q=бюджет` | всички гласувания на едно събрание, с търсене в темата (последните 400; всички в CSV) |
| `/glasuvane/<заседание>/<точка>` | едно гласуване: залата (всеки кръг е депутат, пълни се с анимация), по групи, кой гласува различно от групата си, всички депутати |
| `/deputati?ns=52` | депутатите: участие, с групата, срещу групата, регистрации; районът за сегашното събрание |
| `/deputati/<събрание>/<номер>` | депутат: всяко гласуване във времето (лента), участие по месеци, гласуванията срещу групата |
| `/grupi?ns=52` | единство на групите, по месеци, и кои групи гласуват заедно |
| `/sources`, `/how` | източниците и свежестта; как работи |
| `/api/glasuvane/<заседание>/<точка>.json`, `/api/zala/<събрание>.json`, `/api/deputat/<събрание>/<номер>.json`, `/api/grupi/<събрание>/edinstvo.json` | данните на залата, лентата и графиките |
| `/csv/glasuvaniya-<събрание>.csv`, `/csv/glasuvane/<заседание>/<точка>.csv`, `/csv/deputati-<събрание>.csv` | CSV |
| `/healthz` | базата отговаря |

## Данни

Всичко е от сайта на Народното събрание (`https://www.parliament.bg/api/v1/`, JSON без ключ, и CSV
файловете към стенограмите). Подробно: [docs/sources.md](docs/sources.md); проверките и какво значат
числата: [docs/methodology.md](docs/methodology.md).

- Депутатът е в рамките на едно събрание: системата за гласуване му дава номер само за него. Хора от
  различни събрания не се свързват по име.
- Избирателният район е от списъка на сегашното събрание, свързан по трите имена само когато името е
  веднъж и в двата списъка.
- Не показваме дати на раждане, телефони, имейли и снимки.

## Стъпки

```bash
python -m ingest.run --step migrate
python -m ingest.run --step roster                      # депутатите на сегашното събрание
python -m ingest.run --step sittings --from 2021-12     # наваксване (около 700 заседания, около час)
python -m ingest.run --step sittings                    # от месеца преди последното прочетено заседание
python -m ingest.run --step freshness                   # какво е закъсняло, задържано или невалидно
uvicorn app.main:app --port 8009
```

Всяка стъпка печата един JSON ред; изходът е 1 при грешка или при непразно `problems`.

## Тестове

```bash
PARLAMENT_TEST_DSN="dbname=parlament_test" python -m pytest -q     # базата се изтрива
PARLAMENT_TEST_DSN="dbname=parlament_test" python tests/mutations.py
```

Без `PARLAMENT_TEST_DSN` тестовете с база се пропускат; в CI вървят всички, срещу Postgres 17. Фикстурите в
`tests/fixtures/parliament/` са истински отговори на сайта, байт по байт (всеки вид файл от 12.2021 насам).
`tests/mutations.py` чупи нарочно всяко пазещо правило и проверява, че тестовете го хващат.
