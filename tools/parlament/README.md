# Парламент

Всичко от пленарната зала, откакто има данни: всяко заседание от 1879 г. със стенограмата (като текст
от 1992 г., разделена по изказвания, с търсене; сканирана преди това) и видеото (от 2010 г.); всяко
поименно гласуване от юли 2009 г. (41-во Народно събрание), по депутати и по парламентарни групи, в
залата с анимация; всички събрания, групите и комисиите с датите, депутатите с членствата им и същият
човек в различните събрания; официалните отсъствия и наказанията. Всяко гласуване е сверено:
поименното гласуване, преброено по групи, е гласуването по групи.

## Страници

| Адрес | Какво |
|---|---|
| `/` | изречение с ключовите числа, залата по групи, последното гласуване, последните и най-оспорваните гласувания |
| `/glasuvaniya?ns=52&q=бюджет` | всички гласувания на едно събрание, с търсене в темата (последните 400; всички в CSV) |
| `/glasuvane/<заседание>/<точка>` | едно гласуване: залата (всеки кръг е депутат в цвета на групата си със значка за вота, групите са сектори под дъга в цвета на партията, пълни се с анимация; броячите показват само за, против, въздържали се или не гласували), как гласува всяка група (точка за депутат), кой гласува различно от групата си, всички депутати |
| `/deputati?ns=52` | депутатите: участие, с групата, срещу групата, регистрации; районът за сегашното събрание |
| `/deputati/<събрание>/<номер>` | депутат: всяко гласуване във времето (лента), участие по месеци, гласуванията срещу групата |
| `/grupi?ns=52&date=2026-08-01` | съставът на избран ден (залата), единство на групите, по месеци, и кои групи гласуват заедно |
| `/grupa/<събрание>/<група>` | група: колко депутати във времето, кой е влязъл и излязъл, с кои групи гласува, ръководство |
| `/zasedaniya?g=2026`, `/zasedaniya?ns=41`, `/sabraniya` | заседанията по години или по събрания от 1879 г.; всички събрания и какво пазим от тях |
| `/zasedanie/<id>` | заседание: видеото (вградено от сайта на НС, по части), кой говори, гласуванията, стенограмата по изказвания с търсене; `/zasedanie/<id>/stenograma` отваря само нея (в нов раздел) |
| `/izkazvane/<заседание>/<№>` | едно изказване със собствен адрес, с предишното и следващото |
| `/tarsene?q=…&ns=…&chovek=…` | търсене в изказванията от 1992 г. (всички думи, по началото им), по събрание и по човек |
| `/zakonoproekti?ns=52&q=…&st=priet` | законопроектите на събрание от 2001 г., с търсене по заглавие, сигнатура и вносител |
| `/zakonoproekt/<id>` | законопроект: вносители, комисии, етапи, гласуванията в залата, позицията на всяка група на първо и второ четене и къде се е сменила |
| `/chovek/<човек>` | депутат през всички събрания: линия във времето с групите в цветовете им, райони, листи, длъжности, комисии, гласуване, изказвания, официални отсъствия, наказания |
| `/sources`, `/how` | източниците и свежестта; как работи |
| `/api/glasuvane/<заседание>/<точка>.json`, `/api/zala/<събрание>.json?date=`, `/api/grupa/<събрание>/<група>.json`, `/api/deputat/<събрание>/<номер>.json`, `/api/grupi/<събрание>/edinstvo.json` | данните на залата, лентата и графиките |
| `/csv/glasuvaniya-<събрание>.csv`, `/csv/glasuvane/<заседание>/<точка>.csv`, `/csv/deputati-<събрание>.csv` | CSV |
| `/healthz` | базата отговаря |

## Данни

Всичко е от сайта на Народното събрание (`https://www.parliament.bg/api/v1/`, JSON без ключ, и CSV
файловете към стенограмите). Подробно: [docs/sources.md](docs/sources.md); проверките и какво значат
числата: [docs/methodology.md](docs/methodology.md).

- Системата за гласуване дава на депутата номер само за едно събрание; профилът му (номерът на Народното
  събрание) също е за едно събрание. Същият човек в различни събрания: Народното събрание изброява в
  профила предишните му събрания, а там профилът е този със същите три имена, само ако името е веднъж.
- Събранията от 1879 г. са в `db/ref/assemblies.csv` (от Уикипедия, сверено с API-то от 39-о насам): номерът
  е на обикновеното събрание (1950-1990 продължават номерата: I НС от 1950 г. е 27-о), великото е 100 +
  номера, Учредителното е 100. Събранието на заседание преди 2009 г. е по датата.
- Групите са в цветовете на партиите си (Уикипедия); имената и цветовете са в `db/ref/groups.csv`, където
  преименуваните групи в едно събрание са една. Нова група се добавя там.
- Избирателният район е от профила на депутата, свързан с поименното гласуване по трите имена само когато
  името е веднъж и в двата списъка.
- Не показваме и не пазим в базата дати и места на раждане, телефони, имейли и снимки.

## Стъпки

```bash
python -m ingest.run --step migrate                     # и събранията от db/ref/assemblies.csv
python -m ingest.run --step roster                      # депутатите на сегашното събрание
python -m ingest.run --step people --all                # събранията от 39-о, групите, комисиите, всички профили (около 1,5 ч)
python -m ingest.run --step sittings --from 1879-02     # наваксване: около 9 000 заседания, около ден
python -m ingest.run --step sittings                    # от месеца преди последното прочетено заседание
python -m ingest.run --step recheck                     # отказаните и без четими файлове наново; статистиката наново
python -m ingest.run --step absences                    # официалните отсъствия и наказанията (пазят се само месеци)
python -m ingest.run --step pdfs --limit 500            # архив на сканираните стенограми (преди 1992 г.)
python -m ingest.run --step bills --from 2001-07        # законопроектите (наваксване); без --from: последните два месеца и отворените
python -m ingest.run --step freshness                   # какво е закъсняло, задържано или невалидно
uvicorn app.main:app --port 8009
```

Всяка стъпка печата един JSON ред; изходът е 1 при грешка или при непразно `problems`.

## Тестове

```bash
PARLAMENT_TEST_DSN="dbname=parlament_test" python -m pytest -q     # базата се изтрива
PARLAMENT_TEST_DSN="dbname=parlament_test" python tests/mutations.py
```

Без `PARLAMENT_TEST_DSN` тестовете с база се пропускат; в CI вървят всички, срещу Postgres 17. Фикстурите в
`tests/fixtures/parliament/` са истински отговори на сайта, байт по байт (всеки вид файл от 12.2021 насам).
`tests/mutations.py` чупи нарочно всяко пазещо правило и проверява, че тестовете го хващат.
